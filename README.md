# 🤖 SDAIA Large Language Models Bootcamp Projects

A collection of practical AI, Deep Learning, Natural Language Processing, and Large Language Model projects built during the SDAIA Bootcamp journey.

This repository covers hands-on implementations ranging from neural networks and CNNs to text preprocessing, sentiment analysis, GPT-2, model fine-tuning, transfer learning, RAG, and text classification.

Output: Predictions, Generated Text, Summaries, and AI Insights

## 🚀 How to Run

```bash
git clone https://github.com/RashaAlorabi/SDAIA-Large-Language-Models-Bootcamp.git

cd SDAIA-Large-Language-Models-Bootcamp

python3 -m venv ai-env

source ai-env/bin/activate

pip install -r requirements.txt

jupyter notebook
```

For Windows:

```bash
ai-env\Scripts\activate
```
